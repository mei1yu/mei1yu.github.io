# 🗺️ Web安全与CTF全栈从入门到高手知识地图

> 本知识库专为 **CTF Web 竞赛实战** 与 **Web 渗透测试工程** 打造。
> 编写准则：**拒绝概念泛谈，深挖底层原理，参数逐个拆解，每课必配真实案例/赛题源码。扩展时从通俗生活比喻与基础术语扫盲起步，层层递进直达攻防核心。**

---

## 📌 知识库编写规范 (攻防知识库核心规范)

每个具体知识点笔记必须严格遵循以下 **六维深度结构**：
1. **基础前置知识扫盲区**：通俗生活类比、概念扫盲与基础术语对照，让初学者也能零门槛看懂底层逻辑。
2. **底层运行机制剖析（含 Mermaid 图解）**：解释代码、网络协议、数据库、操作系统或解释器层面的数据流与执行过程。
3. **Payload 语法与参数逐字详解**：**每一个函数、关键字、闭合符、十六进制参数、命令行开关的作用均逐项拆解剖析**。
4. **硬核实战例题（靶场/CTF真题）**：题目背景 + 漏洞源码片段 + 详细利用步骤与网络交互 + 避坑指南。
5. **纵深防御机制与安全加固基线**：企业级安全编码、WAF/RASP规则加固与系统基线防范。
6. **双向链接体系（Obsidian 语法）**：模块间无缝互联，构建高聚合知识图谱。
